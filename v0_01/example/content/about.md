# About

This is a tiny example site that exercises the features of `ssg` `v0_01`:

1. Markdown conversion (headings, lists, links, code).
2. `{{title}}` / `{{content}}` template substitution.
3. Recursive directory mirroring — see `posts/hello-world.md`.
4. Static asset copying — see `style.css`.

The whole site is generated by one command:

```text
ssg build
```
