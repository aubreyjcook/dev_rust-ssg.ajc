# About

This is a tiny example site that exercises the features of `ssg` `v0_02`:

1. Markdown conversion (headings, lists, links, code).
2. `{{title}}` / `{{content}}` / `{{base_url}}` template substitution.
3. Per-page front matter (`title:` and `template:` overrides).
4. Recursive directory mirroring — see `posts/hello-world.md`.
5. Static asset copying — see `style.css`.

The whole site is generated by one command:

```text
ssg build
```

To preview how it would behave hosted in a subdirectory, build with a base
URL:

```text
ssg build --base-url /my-site
```
